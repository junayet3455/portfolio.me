# Portfolio

Pages: index.html, experience.html, qualification.html, contact.html, admin.html
Styles: css/style.css   Code: js/data.js (your content), js/script.js (pages), js/admin.js (admin panel)

## Edit
Open admin.html (passcode is in js/admin.js, default admin123), edit, press Save to preview,
then Download data.js, replace js/data.js, and commit and push.

## Publish on GitHub Pages
Push this folder to a repository, then Settings > Pages > Deploy from branch (main, / root).

## Change the design
Easy way: admin.html > Design (colours, font, photo shape), Save, then Download data.js.
By hand: edit the "theme" block at the top of js/data.js, or the rules in css/style.css
(spacing, sizes, card style). The colour variables are at the top of style.css.
